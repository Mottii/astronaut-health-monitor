# Презентация ARES-MED

Файлы Forma Studio и готовые промпты в этой папке сохраняют историю исходного задания. Они не заменяют последние требования к работающему приложению.

Текущая реализация:

- `src/components/PresentationStory.tsx`: семь слайдов — титульный ARES-MED, контекст миссии и пять глав диагностики. Прежний финал CMO заменён титульником и перенесён в начало. Нативная прокрутка замкнута через совпадающие копии крайних слайдов: после последнего титульник появляется как следующая глава. Стартового модального экрана нет; звук включается линейной иконкой эквалайзера в шапке. Контрастные подписи систем соединены с органами проецируемыми линиями.
- `src/lib/briefingPath.ts`: замкнутая непрерывная траектория камеры и плавное распределение внимания между системами, включая переход из последней главы в первую.
- `src/components/BioTwin3DStage.tsx`: приглушённые анатомические цвета, затухание второстепенных органов, небольшое приближение выбранной области, мягкое покачивание и независимое вращение тела вокруг вертикальной оси.
- Полигональная подсветка при наведении, квадратная сканирующая плоскость и астероиды удалены. Фон заполняют мягкие сине-фиолетовые газовые облака, редкие звёзды и далёкие световые частицы на орбитах позади тела.
- `src/lib/constellationField.ts`: мелкие белые звёзды и пять декоративных созвездий по мотивам охотника, лиры, лебедя, короны и дракона. Тонкие линии постепенно проявляются и исчезают у краёв экрана. Проецируемая область тела с запасом исключена из линий и узлов созвездий, в том числе при вращении и приближении. Режим уменьшенного движения оставляет статичное звёздное поле.
- Органы метаболической главы используют близкие медные, розовые и персиковые оттенки. Соседние структуры отличаются светлотой, без сильного свечения. Белый контур тела усилен для отделения от фона.

Управление: вертикальная прокрутка или клавиши стрелок/Page Up/Page Down; горизонтальное перетаскивание свободной области сцены вращает тело. Клавиши `[` и `]` также вращают модель. Точки справа выбирают главу. Настройка уменьшенного движения доступна при клавиатурном фокусе.

Проверка: `npm test`, `npx tsc --noEmit`, `npm run build`. Для сборки рядом с работающим dev-сервером задайте переменную `ARES_BUILD_DIR=.next-production`; обычный dev-сервер продолжает использовать `.next`.

Превью и временные кадры сохраняются локально в `output/` и `tmp/` и не входят в Git. На титульном слайде и в контексте миссии фигура занимает почти всю высоту большого экрана; на телефоне сохраняется место для текста. CMO-консоль доступна из шапки на каждой главе.
